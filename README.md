# Student Registration System 🎓

A web-based system to help KAMPALA INTERNATIONAL UNIVERSITY manage student registration, course selection, and data storage.

### 🎯 Problem We're Solving
Long queues, paper forms, and lost student data during registration week.

### ✨ Key Features - v1.0
- [ ] Student Registration Form
- [ ] Admin Dashboard to view all students
- [ ] Course Selection
- [ ] Export data to Excel
- [ ] Login for Admin + Student

### 🛠️ Tech Stack
- **Backend**: PHP
- **Database**: MySQL
- **Frontend**: HTML, CSS, Bootstrap
- **Version Control**: Git & GitHub

### 🚀 How to Run Locally
1.  Clone the repo: `git clone https://github.com/CampusDevsCollective/student-registration-system.git`
2.  Import `database.sql` into phpMyAdmin
3.  Configure `config/db.php` with your DB credentials
4.  Run on `localhost` using XAMPP
